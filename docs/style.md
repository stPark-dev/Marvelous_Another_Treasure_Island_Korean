# 번역 가이드 (마벨러스 한글화)

번역자(사람·에이전트 공통) 입력 패키지. 근거 결정은 `docs/decisions.md`(D5–D8), 맥락은 `docs/context.md`, 용어는 `data/glossary.json`, 문체 기준은 승인된 샘플 `text/reference/sample_eval.json`.

## 1. 파일 형식

배치 파일 `text/ko/bNN.json`:

```json
{"batch": "b01", "source_sha256": "555d78c9…", "entries": [
  {"id": 4, "src": "<원문 raw hex 그대로>", "jp": "<원문 표시 그대로>",
   "ko": "<번역>", "state": "needs_review", "note": "", "question": ""}
]}
```

- `id`, `src`, `jp`는 **보호 필드**. `text/script_jp.json`에서 그대로 복사하고 절대 고치지 않는다.
- `ko`만 쓴다. `state`는 초벌 완료 시 `needs_review`.
- `note`: 해석 근거·불확실성. `question`: 사람이 정해야 하는 것(말장난 각색, 수수께끼 답, 화자 불명 등). 비어 있으면 `""`.
- 빈 메시지(`<FB>`/`<FA>`만 있는 것)는 `ko`를 원문과 같게(`"<FB>"`) 둔다.

## 2. 토큰 규칙

| 표기 | 의미 | 규칙 |
|---|---|---|
| `<F8>` + 줄바꿈 | 일반 줄바꿈 | 위치·개수 자유. 한국어 줄 나눔에 맞게 옮겨도 됨 |
| `[F9]` | 버튼 대기 후 다음 페이지 | 위치·개수 자유. 한 페이지는 3줄 이하 |
| `[F6]` | `[FE69]` 블록·선택지 안의 줄바꿈 | **개수와 순서 유지**. 문장 안에서 위치는 옮겨도 됨 |
| `[FE69]` `[FE6A]` `[FE68]` 등 `[FE..]` | 블록 시작·선택지·삽입 | **개수·순서·인자 그대로** |
| `[FE6D1A]` | 플레이어가 지은 팀 이름 | 뒤에 항상 ` 팀`을 붙여 조사는 `팀`에 붙인다: `[FE6D1A] 팀은` |
| `[FE6D34]` `[FE6D56]` | 현재 리더 이름(디온/맥스/잭) | 뒤에 ` 군`을 붙인다(조사 회피, D8) |
| `[FE6B]` `[FE6C]` `[FE6D20]` 등 | 숫자·아이콘 삽입 | 그대로 두고 단위(개, 명, %)를 맞춘다 |
| `[F5xxxx]` `[F2]` | 효과음·이벤트 | 그대로 |
| `<FA>` / `<FB>` | 메시지 끝 | 원문과 같은 것 하나로 끝낸다 |

- 띄어쓰기는 ASCII 공백 ` `(반칸, 8px). 원문의 전각 공백 `　`(한 칸)은 들여쓰기·서명 정렬·선택지 들여쓰기에서만 원문처럼 유지한다.
- 한 줄은 **최대 22칸**(한글·전각 1칸, 반각 공백 0.5칸). 줄은 `<F8>`, `[F6]`, `[F9]`, `[FE69]`, 메시지 끝에서 끊긴다.
- 원문 한 페이지 줄 수(보통 1~2줄)를 크게 넘기지 않는다.

## 3. 표기

- 쓸 수 있는 문자: 한글 음절, 숫자 `0-9`, 영문, `. , ? ! ~ … ー · 「 」 /`. 일본어 문자는 남기지 않는다.
- `・・・` 말줄임은 `……`(두 글자 정도)로. `、`→`,` `。`→`.` `！`→`!` `？`→`?`.
- 동물 울음의 장음은 `ー` 또는 `~`. 예: `삐롯삐이ー, 삐로로`.
- 숫자는 아라비아 숫자(`2시간`, `3호 텐트`). 고유 수사가 자연스러우면 한글(`세 개의 열쇠`).
- 드문 음절은 피한다. 글꼴 슬롯은 약 930음절로 제한되어 있다. 같은 뜻이면 흔한 낱말을 쓴다.

## 4. 말투

- 주인공 세 아이(디온·잭·맥스): 또래끼리 반말, 어른에게 존댓말. 인물별 일인칭·말버릇은 `docs/context.md` §3을 따른다.
- 지나 선생님: 아이들에게 다정한 반말(`~렴`, `~해 줘`). 아이 이름에 붙는 `君`은 생략(D8).
- 장로(`~じゃ`): 예스러운 `~느니라/~거라`.
- 동물 대사: 울음소리 + 줄바꿈 + `번역: …`(D7).
- 세자르(`ザンス`): `~라구/~다구`, 가끔 `~라니깐`(D7).
- `ザーマス` 부인: `~하와요/~사와요` 같은 사모님 말투(D7).
- 로봇·고문서 가타카나 말투: 낱말 사이를 전각 공백으로 띄우고 조사도 떼어 쓴다(예: `초록　보물상자　를　찾아라`).

## 5. 사람 판단이 필요한 것

말장난 이름(`data/glossary.json`의 `scene_review`), 숫자 수수께끼(0226, 0228, 0238, 0253–0264), 퀴즈(0525–0532), 그림 순서 퍼즐(0619–0630), 노래 패러디(2273, 2516, 2518), 선인장 하이쿠(0473 등): 자연스러운 각색안을 `ko`에 넣고, `question`에 원래 의미·각색 방식·대안을 적는다. 정답·힌트가 다른 메시지와 맞물리면 관련 ID를 모두 적는다.

## 6. 제출 전 검사

